# 简历 · 项目介绍

## 项目名称

**能源互联网智能体（EnergyInternet Agent）** —— 多智能体能源优化问答系统

> 技术栈：Python · FastAPI · OpenAI 兼容协议（DeepSeek）· 自研多智能体框架 · HTML/CSS/JS · ECharts

## 项目描述

面向「源网荷储」协同与能源节约的智能体系统：用户以自然语言提问，主控智能体自动理解意图、
路由 6 个专职子智能体（负荷预测 / 新能源 / 储能 / 调度优化 / 能耗诊断 / 碳核算）调用领域工具
取数分析，输出可量化的优化结论；前后端与智能体框架全程自研，约 16 个文件、核心框架约 200 行。

## 工作内容

1. **自研轻量多智能体框架**：实现 `Tool / Agent / Supervisor` 三层抽象与 ReAct 决策循环，
   以「子智能体即工具」实现主控对 6 个专职子智能体的层级委派与结果汇总，替代 LangChain/LangGraph 等重框架。

2. **设计结构化决策协议与两阶段流式**：让 LLM 通过 `{"action":"tool"|"finish"}` 决策、
   不依赖原生 function-calling 以兼容任意 OpenAI 模型；工具循环非流式保证稳定、最终回答真流式保证体验。

3. **搭建 FastAPI + SSE 流式后端**：以 `asyncio.Queue` + 后台任务解耦智能体执行与推送，
   定义 agent/tool/tool_result/text 事件协议，实现逐字流式输出与「思考过程」轨迹实时回传。

4. **构建 ChatGPT 风格前端与可视化面板**：原生 HTML/CSS/JS + ECharts，手写 Markdown 渲染器与
   SSE 流解析，实现源网荷储曲线面板、可折叠思考轨迹、多会话 localStorage 持久化。

5. **领域数据、调度算法与测试**：编写贴近我国电力现状的模拟数据与 8 个纯函数工具
   （含储能峰谷套利贪心调度），用 StubLLM 注入实现无 Key 全链路单测，并接入 DeepSeek 完成
   真实模型端到端验证（储能套利策略输出年收益约 548 万元等量化结论）。
