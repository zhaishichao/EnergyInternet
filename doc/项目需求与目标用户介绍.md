# 能源互联网智能体 · 项目需求与目标用户介绍

## 一、项目定位

面向我国电力与新能源发展现状，帮助园区、工厂与能源企业，用「对话」的方式完成负荷预测、
新能源消纳、储能套利、调度优化、节能改造与碳核算的一体化能源优化助手。

## 二、核心需求：为什么需要它

当前我国电力系统正处在转型期，能源管理者普遍面临六类真实痛点：

1. **新能源「接得多、用不好」**：光伏、风电装机快速增长，但出力靠天吃饭，弃风弃光、消纳困难；
2. **峰谷差越拉越大**：空调用电、电动汽车等负荷增长，峰谷差逐年扩大，电网调峰压力大、设备利用率低；
3. **储能「该充不充、该放不放」**：分时电价价差扩大带来套利空间，但何时充放、充放多少缺乏量化方案；
4. **能耗高却不知从何下手**：用能结构不透明，节能改造缺方向、缺数据支撑；
5. **碳排放「不会算、不知道怎么降」**：双碳目标下，企业需要核算排放、匹配绿电、规划减排路径；
6. **各环节各自为战**：源、网、荷、储各管各的，缺乏协同，难以形成整体最优。

这些痛点的共同点是：**专业门槛高、数据分散、需要跨领域协同**——而这正是「大模型 + 多智能体」
擅长解决的场景。

## 三、目标用户

| 用户 | 典型诉求 |
|------|---------|
| 园区 / 工厂 / 商业综合体的能源管理员 | 降本：削峰填谷、储能套利、节能改造 |
| 售电公司 / 虚拟电厂 / 微电网运营商 | 协同：源网荷储调度、需求响应、绿电匹配 |
| 能源 / 双碳方向的咨询与研究人员 | 分析：负荷预测、碳核算、减排路径 |

## 四、主要解决的能源问题

| 能源问题 | 本项目如何解决 |
|---------|--------------|
| 新能源出力随机、消纳难 | 结合负荷曲线评估光伏风电出力与消纳，量化弃风弃光风险 |
| 峰谷差大、调峰难 | 负荷预测 + 削峰填谷建议，降低峰值、提升设备利用率 |
| 储能利用率低、套利无方案 | 基于分时电价给出「谷充峰放」计划，量化套利收益 |
| 能耗高、节能无方向 | 分项能耗诊断，定位高耗能环节并给出改造建议 |
| 碳排放不会算、不知道怎么降 | 结合排放因子与用能数据核算碳排放，给出减排路径 |
| 源网荷储割裂、协同难 | 一体化协同调度，输出充放电计划、套利收益与削峰率 |

## 五、技术如何支撑这些需求（简要）

- 用**大模型**理解自然语言，降低专业工具的使用门槛；
- 用**多个专职智能体**各司其职（负荷 / 新能源 / 储能 / 调度 / 能耗 / 碳），由主控智能体自动路由与汇总；
- 用**分时电价、负荷曲线等数据工具**做量化计算，让结论「有数字、可执行」；
- 通过**可视化面板与流式问答**，让分析过程和结果一目了然。

## 六、价值总结

把能源优化从「依赖专家 + 割裂工具」变成「自然语言提问 + 一键式协同分析」，让能源管理更简单、
更量化、更可执行。
