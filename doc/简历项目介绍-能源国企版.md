# 项目介绍（能源类国企求职版）

## 能源互联网智能体 · 多智能体能源优化系统

> 技术栈：Python · FastAPI · 大模型（OpenAI 兼容协议）· 自研多智能体框架 · ECharts

### 一、项目介绍

围绕我国**新型电力系统建设**与**「双碳」目标**下「源网荷储」协同的迫切需求，独立开发的一套
多智能体能源优化系统。系统以自然语言为入口，主控智能体自动理解用户诉求，调度负荷预测、
新能源消纳、储能套利、调度优化、能耗诊断、碳核算 6 个专职智能体，调用分时电价、负荷曲线等
专业工具完成量化分析，为园区、工厂及综合能源企业提供「源网荷储一体化」决策支持，助力降本
增效与绿色低碳转型。

### 二、主要职责

1. **业务需求与场景梳理**：将新能源消纳难、峰谷差扩大、储能套利、能耗诊断、碳核算等真实痛点，
   拆解为 6 大智能体场景与对应专业数据工具；
2. **多智能体框架设计开发**：自研「主控 + 子智能体」层级委派架构与 ReAct 决策循环，实现任务
   自动路由、专业分工与结论汇总；
3. **数据建模与调度算法**：构建贴合实际的峰谷分时电价（价差 0.98 元/kWh）、负荷 / 风光出力曲线、
   碳排放因子等数据，实现储能峰谷套利调度算法；
4. **系统开发与可视化**：完成 FastAPI 流式问答后端与可视化前端，实现「思考过程」轨迹、
   源网荷储曲线面板、多会话管理；
5. **测试验证与联调**：编写无 Key 全链路单元测试，接入真实大模型完成端到端验证。

### 三、效果 / 成果

1. **储能套利可量化**：输出「两充两放、尖峰优先」充放电策略，经真实大模型测算年套利收益约 **548 万元**；
2. **六大场景一体化**：覆盖负荷预测、新能源消纳、储能套利、调度优化、节能诊断、碳核算，
   形成源网荷储协同分析能力；
3. **结论可执行**：各场景输出均含关键数据 + 量化收益 + 行动建议，可直接支撑能源管理决策；
4. **系统可落地可演进**：全链路端到端跑通并通过真实大模型验证，具备接入真实数据源与
   MCP 标准工具的扩展能力。
